# Font untuk gambar yang dibuat server

`Poppins-Regular.ttf` dan `Poppins-Bold.ttf` dipakai `app/(public-docs)/certificates/[code]/image/route.tsx`
supaya nama dan judul di sertifikat PNG tampil tebal. Renderer gambar (`next/og`)
tidak bisa memakai font dari `next/font`, jadi file aslinya disimpan di sini.

Poppins dibuat oleh Indian Type Foundry dan dirilis dengan SIL Open Font License 1.1
(https://openfontlicense.org). Lisensi ini mengizinkan font disertakan bersama
perangkat lunak, selama font tidak dijual terpisah.
